Build a simple, stylish, mobile-first trading habit tracker web app.

Core concept

This is NOT a traditional trading journal. It is a fast, swipe-based trading discipline tracker.

The user should be able to complete a trade journal in 30–60 seconds with almost zero typing.

Design

- Premium, minimal, modern UI
- Mobile-first
- Dark theme
- Clean typography
- Smooth animations
- Large touch-friendly buttons
- Card-based interface
- Swipe/drag interactions
- Progress indicator such as "2 / 6"
- Avoid clutter
- Avoid unnecessary text fields
- Everything should feel quick and interactive

Main navigation

Create 4 main sections:

1. Dashboard
2. New Trade
3. Trade History
4. Analytics

DATA

Use a proper database so trades persist after refresh.

Each trade should store:

- Date/time
- Before-trade answers
- During-trade answers
- After-trade answers
- Result
- Discipline score
- Screenshots
- P&L if entered
- Mistake category

For P&L, allow a simple optional numeric input only in the After Trade stage. Everything else should use buttons/toggles.

---

IMPORTANT UX RULES

- Almost no typing.
- One question per screen.
- Large buttons.
- Automatically advance after selection where appropriate.
- Swipe gesture for moving between stages.
- Allow back navigation.
- Show progress.
- Save progress so accidental refresh doesn't lose the trade.
- Make screenshot upload extremely easy.
- Responsive on Android phones.
- Fast loading.
- No unnecessary features.
- No complicated settings.

Technical preference

Build it as a mobile-first PWA/web app that can later be packaged as an Android app.

Use a modern React-based frontend with clean reusable components and a database/backend suitable for Replit.

Before adding advanced features, make the core trading flow fully functional and polished.

The final result should feel like a premium minimalist trading discipline app, not an Excel sheet or traditional journal.
